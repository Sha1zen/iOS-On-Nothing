# Survey notes — 2026-10-17

## Chosen path

**Reference architecture:** anurodhp's Darwin-on-RPi3 ecosystem
(xnu-7195 from source, `MACHINE_CONFIGS=BCM2837`, QEMU `raspi3` first,
real HW second; real launchd PID 1 + GNUstep). Cloned into `reference/`:

- `reference/xnu-pi3-macos11` — kernel tree (full fork of
  apple-oss-distributions/xnu, branch-equivalent "bcm2837-bringup");
  last commit yesterday: pexpert DT frequency-property fix. Key platform
  files: `pexpert/pexpert/arm64/BCM2837.h`, `board_config.h`,
  `pexpert/arm/pe_init.c`, `pe_serial.c`.
- `reference/xnu-iokit-pi3` — the project hub: `architecture.md`,
  `CLAUDE.md` (build rules incl. Xcode versions), `build_everything.sh`,
  `runvm.sh` (exact QEMU invocation), `devicetrees/`, `sdcard/`,
  `tools/userland_staging/`, `docs/` (roadmap migrated to Linear,
  `docs/historic/*` has phase-by-phase history).
- `reference/qemu-xnu-arm` — their own QEMU fork for running rpi3 kernel.

**Boot chain (QEMU, reference):**
`qemu-zhuowei/aarch64-softmmu/qemu-system-aarch64 -M raspi3,xnu-smp=on
-serial stdio -kernel build/xnu-latest-build/out/kernel.development.bcm2837-7195.unstripped
-dtb devicetrees/rpi3.dtb -drive file=SD,if=sd
-append "debug=0x8 kextlog=0xfff -noprogress -v -enable_kprintf_spam
rd=disk0s2 serial=3 cpu-factor=10 vm_compressor=0"`
- QEMU is Zhuowei's fork (2.12.91 + DWC2 backport): parks secondary cores
  like real firmware; plain upstream qemu cannot boot it (per runvm.sh).
- `runvm_hdmi.sh` adds real framebuffer window + `hdmi_console=1`.

**Build environment (reference, from CLAUDE.md):**
- Kernel: `iPhoneOS` SDK from the live Xcode (NOT `SDKROOT=macosx`).
- kexts: Xcode 12 specifically, `DEVELOPER_DIR=/Applications/Xcode-12.app`.
- userland: Xcode 12 iPhoneOS SDK, freestanding archives.
- third_party via `setup_third_party.sh` (forks: xnu-7195, u-boot
  [anurodhp fork of FlorentRevest], dtc-appledevicetree, dyld/Libc/
  libpthread IOKit-port branches, hfs/msdosfs/IOStorageFamily Apple tags …).

**Alternative historical paths (surveyed, not chosen):**
- alephsecurity/xnu-qemu-arm64: iOS 12.1 kernel from IPSW in patched QEMU
  (S8000 machine). Great docs but Apple-blob based. Boot command from their
  tutorial: `-M iPhone6splus-n66-s8000,kernel-filename=...,dtb-filename=...,ramdisk-filename=...,tc-filename=static_tc".
- Khadas VIM3 (minos hypervisor, 2020): stock iOS kernelcache on real ARMv8;
  traps: 16K FVP granule, CPACR_EL1=0x300000, DC ZVA fixed-64B, SHA-256
  extension required, physical timer on FIQ.
